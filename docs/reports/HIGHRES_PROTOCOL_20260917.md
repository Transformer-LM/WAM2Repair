# 高分辨率修复探索实验（用户授权 2026-09-17）

## 固定设计

仅改变双视角分辨率：112×224 → 224×448（每视角224×224）。冻结原始WAM、π0.5、151窗口及原episode划分；不加入用户偏好的六个案例作为训练数据或选模依据。相同UnifiedVideoRepair、seed17、AdamW lr1e-3、WD1e-4、batch4、1000步、梯度裁剪1、future L1+0.1 temporal L1。repair与no-WAM都训练；原始WAM、当前帧复制、anchored作为对照。每50步仅validation选模。

测试集已被查看，本轮属于探索性跟进，不是新的独立确认实验。未来主结论需要未查看的新episode。旧低分辨率结果保持不变。

## Gate及判据

1. 三个train窗口、224×448、100步单批容量gate：有限loss、最终loss低于初始80%，否则不启动完整训练。
2. 通过后repair/no-WAM各1000步单卡。主要描述指标：原生224×448上的test episode-macro future MAE；repair需低于raw且不劣于copy/no-WAM才有进一步扩展的像素证据。
3. 分辨率间比较必须统一评估网格，不能直接比较旧112×224 MAE与新224×448 MAE；旧checkpoint将在224×448真值网格上评估（低分辨率输出双线性上采样）。报告额外计算与显存，非等FLOPs实验。
4. 接触/姿态/穿模属于后续独立评测，不用像素MAE代替。准备包含完整轨迹、终止尾帧的真实参考；短窗口预测不能冒充整段预测，不能重复或拼接成伪连续完整抓取。
