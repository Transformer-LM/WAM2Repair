# 深度辅助统一视频修复：最小训练协议

在已通过几何数据 gate 后执行用户授权的第一步学习实验。固定原 manifest 前三个 train 窗口，与先前 RGB sanity 一致；不读 val/test 数组。每视角224×224，五帧双视角；seed17，AdamW lr1e-3、weight_decay1e-4、梯度裁剪1，每组300步，整批3窗口。

两个完全相同初始化与结构的模型：RGB-only 与 RGB+depth。共享 3D 编码器，预测正深度，并把预测深度拼接进 RGB 残差输出层；没有未来真值输入，没有预训练深度估计器。深度在训练期间是监督目标，在推理期间是网络内部预测。
loss = future RGB L1 + 0.1 temporal RGB difference L1 + lambda depth log L1，lambda 分别0和0.1。无独立depth输入，不能称已验证用户提出的外部单目深度估计路线。

先核验源hash/时间；从原生监督深度重新执行180度旋转与最近邻resize，与已导出224深度逐元素核对。沿用已验证原生RGB/depth同像素约定。本轮只做像素监督、不用K或三维投影；rendered-landmark见证仍是三维约束的前置条件，不再错误地阻挡无需三维投影的深度辅助训练。

报告两组从0到300步每25步loss、RGB MAE、depth log MAE；保存末步checkpoint与预测。检查深度loss到共享encoder、RGB loss到深度head的梯度非零且有限。训练可学习性检查仅要求RGB误差下降且带深度组深度误差下降，不再用任意100步20%门槛判断方向失败。该检查不触发自动扩大训练。

限制：三train窗口、单seed，仅接口/优化诊断；不证明泛化、几何正确、真实接触恢复、无穿透、正确未来保持或VLA提升。位置、SO(3)旋转、接触与SDF尚未接入；几何头指标不能当输出RGB物理认证。下一步先基于此结果检查优化与身份保持，再扩充完整几何与留出评估。

计算：复用既有fastwam-py311，无安装/环境变更；单GPU3，启动前即时检查<500MiB、<=5%、无compute进程，忙则不启动；预计数分钟，硬上限1800秒（0.5 GPU小时）。不修改GPU2旧服务，不运行真实机器人。
