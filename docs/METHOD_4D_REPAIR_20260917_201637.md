# WAM2Repair-4D 网络设计候选

状态：待D0标签/几何解析gate后实现，未部署。目标仍是一个统一RGB视频修复器；4D为内部中间表示，不改成只输出状态。R1/R2 representation，未来U3 candidate-action evaluation；冻结WAM/π0.5，模拟器配对监督，非policy RL/co-evolution。

## 数据流

当前RGB/机器人状态 + 固定候选动作 + WAM视频
→ 非特权几何解析（depth/pointmaps、object/robot identity、pose/track、confidence）
→ 同一初始相机/世界参考系中的时间对应tokens
→ 一个action-conditioned时序几何修复模块
→ 修正的对象SE(3)、robot joints/links、接触关系与置信度
→ 可微投影/遮挡感知几何warp得到空间条件和粗视频
→ 几何条件化时序RGB残差解码器
→ 修复视频（附内部geometry供诊断）。

一个网络/统一时序模块服务全部错误类型，不训练多个孤立修复器。不以加loss数量作为能力证明。

## 组件与输入边界

1. 几何解析器：优先核验可离线使用的预训练视觉几何模型，再在train factual上校准；当前已盘点server models目录只有fastwam/openpi，未确认独立depth模型权重。不能声称现成4D解析器已可用。备选先训练受控已知几何视觉解析器，但其精度必须单独过gate。
2. Depth必须配K、相机运动、尺度锚定、同一对象的跨帧identity。跨WAM两视角的不一致应进入confidence，而不是强行融合。未来腕相机位姿来自非特权robot-motion估计，不能偷用GT未来extrinsic作为模型输入。
3. 时序模块第一版可采用小型Transformer，object/link tokens携带pose、canonical点、时间与动作条件；规模在单卡sanity后锁定。先不引入多套大扩散网络或全场景NeRF/4D-GS。
4. Robot采用已知运动学与link collision geometry。当前robot joints必须是可测输入；不能由单个eef pose假设唯一反解，也不能把sim对象qpos夹带进去。对象canonical几何采用known-geometry受控条件，未知形状推广另测。
5. RGB输出不能只拼一个depth通道让网络自由忽略。用预测几何决定warp/visibility/coarse layout，RGB残差处理外观与补洞；所有生成条件在训练和推理都来自预测，不用未来GT teacher-forcing后假装可部署。

## 损失如何对应能力

| 能力 | 训练信号与作用位置 |
|---|---|
| RGB修复 | 真实同动作未来RGB重建/时序损失，局部与全图均报告 |
| 位置 | 米制translation和eef–object相对位姿，作用于几何修复输出 |
| 旋转 | 对称性感知SO(3)测地损失及canonical点位置；不是Euler角MSE |
| 4D运动 | 同身份点的跨帧位移、速度及必要的角速度匹配GT；不用单纯最小运动惩罚冻结视频 |
| 接触 | GT接触分类与配对表面距离；对真实接触/非接触分别约束，不一律鼓励靠近或分离 |
| 穿透 | 预测robot-link/object geometry上的带容差signed-distance barrier，如max(0,-sdf-epsilon)，前提是有有效SDF/collision几何；旧contact距离绝不能代替 |
| 输出一致性 | 预测几何驱动的可微warp/render条件，加RGB端可校准的几何/重投影一致性约束；验证反传路径与输出敏感性 |
| 保持能力 | 正确未来identity、实际失败未来保持、动作条件反事实测试；不把目标任务成功当每个样本的修复target |

接触loss与穿透loss必须成对设计，避免把夹爪远离物体作为“去穿透”。GT物理仿真含solver容差，不能把合法接触强制零距离无重叠。旋转、位置与接触只在标签valid处计算。

## 不允许的捷径

- 只让geometry head与GT一致，却没改变RGB图像中物体关系。
- 仅用自身depth/pose输出评估自身RGB修复。
- 用未来GT segmentation/pose/camera/mesh placement直接渲染正确未来，再把它当网络预测。
- 通过改变原候选动作或把真实失败画成成功来提高分数。
- 将单目伪深度当不可质疑的碰撞真值。

## 首先检验的机制

先用GT几何作为明确oracle诊断几何→RGB解码能否表达修复上限，不计部署成绩；随后用预测几何替换，检查差距。用真实train小集测loss梯度尺度/方向、geometry扰动对RGB布局的实际影响、identity、相同当前帧不同动作敏感性。对比RGB-only、仅depth辅助与有显式4D/输出约束的版本。

独立评价输出RGB时使用冻结、单独校准且不参与修复训练的视觉几何检查器；其在生成视频上的偏差与不可判别率必须报告。校验器失败时只能报告内部几何proxy，不能认证像素中的三维穿透。穿透是高风险claim，必要时增加多视角/mesh可验证的受控子集，不宣称深度万能。
