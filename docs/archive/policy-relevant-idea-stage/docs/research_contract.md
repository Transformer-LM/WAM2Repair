# WAM2Repair 研究契约（恢复记录 2026-09-17）

用户目标：训练独立、动作条件化的统一未来 RGB 视频修复模型，修复冻结 WAM 预测中的接触、位置、旋转、穿透和时序错误，最终改善冻结 π0.5 的候选动作选择及 LIBERO 闭环表现。不是显式状态修复替代最终视频输出，不是把真实失败未来改画成成功。

主要待证主张：
1. 在未见 episode 的真实 WAM 预测上，比 raw、copy-current 与同预算 no-WAM 对照更准确地恢复与指定动作一致的物理未来，并保持正确/失败未来。
2. 这种修复改善候选动作排序和模拟闭环成功率，额外数据、算力和推理成本单独计量。

目前两项均未证实。现有 RGB pilot 仅改善 raw 像素 MAE，仍输给 copy/no-WAM。最新几何数据 gate 只验证训练监督可用。当前执行 DEPTH_SANITY_PROTOCOL_20260917.md：3 train 窗口、单 seed、同模型两损失设置，是优化与梯度连通性诊断，不是主结果。

评估必须使用真实执行的模拟器未来；合成扰动仅能诊断，模型估计深度不是GT。未来 RGB/depth/pose 只能作监督或明确 oracle，不能输入可部署修复器。数据按 episode 分组，已查看 test 不再作独立确认集。物理指标与像素指标、控制指标分开报告。

安全：仅个人目录、既有环境，GPU立即空闲检查，禁系统修改/他人进程/自主真实机器人。

本地技能引用的 RESEARCH_CONTRACT_TEMPLATE.md 未在技能目录发现；本记录按当前用户目标与已有协议建立，不补造研究结论。
